Flash Note Text é um plugin do uTools para anotações temporárias e conversão de texto. Ele reúne edição de texto puro, Markdown e código com histórico, recuperação de rascunhos, formatação, detecção de codificação, compartilhamento de imagens e IA opcional.

## Apoie o projeto

## Recursos

- Modos texto puro, Markdown e código; mostra o código-fonte dentro da marcação Markdown e o resultado renderizado fora dela.
- Histórico, salvamento automático, recuperação de rascunhos, busca, pré-visualização, renomeação, exclusão e ordenação.
- Limpeza de quebras de linha, espaços, escapes, números de citação, links, pontuação e espaçamento CJK/latino.
- Seleção automática ou manual da linguagem de código com CodeMirror e Shiki.
- Suporte a UTF-8/16/32, GBK, GB18030, Big5, Shift_JIS, EUC-KR, Windows-1252 e Latin-1.
- Imagens de notas, código, Xiaohongshu, Zhihu, WeChat e X.
- Interface em 14 idiomas, incluindo português, inglês, chinês, japonês, vietnamita, coreano, espanhol, francês, russo, alemão e italiano.

## Instalação e desenvolvimento

1. Instale e abra o [uTools](https://u.tools/).
2. Baixe um pacote em [GitHub Releases](https://github.com/realSilasYang/flash-note-text/releases) ou compile localmente.
3. Carregue a pasta `dist` gerada nas ferramentas de desenvolvimento do uTools.

```powershell
npm install
npm run release:build
```

Consulte o [README em chinês simplificado](../README.md) para o guia completo, atalhos, limites de dados e desenvolvimento.
